## Other ways to help

Money is not the only way. These help just as much:

- **Report bugs and request features** on the
  [issues page](https://github.com/dheerajshenoy/lektra/issues).
- **Translate Lektra.** There is an English and a Spanish translation; more are welcome.
- **Improve the documentation** and the man page.
- **Contribute code.** Start with
  [CONTRIBUTING.md](https://codeberg.org/lektra/lektra/src/branch/main/CONTRIBUTING.md).
- **Tell others** who read a lot of PDFs, papers or books.

## The reminder in the app

Lektra can show a small, dismissible reminder that it can be supported. It
appears only after a few weeks of use and at most twice a year, and
*Don't ask again* ends it for good.

- To see the support dialog yourself, use **Help ▸ Support Lektra** or the
  `donate` command.
- To turn the reminder off, set `reminders = false` in the `[donate]` section of
  `config.toml`:

```toml
[donate]
reminders = false
```
